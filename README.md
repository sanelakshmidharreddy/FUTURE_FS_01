⚙️ Tech Stack

- React + Vite

- Tailwind CSS
- EmailJS (for contact form)
- Vercel (deployment)

✨ Features

- Responsive UI (mobile + desktop)

- Skills & experience sections
- Contact form with email integration
- Clean modern design
